# Auth and Security E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the whole e2e journey with relay auth on (real RS256 signatures against a local JWKS stub), add an auth matrix, a user-isolation check and the pentest suite to the journey, and unit-test the untested auth paths.

**Architecture:** `AuthStub` (driver) generates a key, serves JWKS on loopback and mints tokens; the fake `az` mints the same tokens for the agent/proxy; a `sitecustomize.py` on the relay's `PYTHONPATH` redirects `shared_auth.validate._get_jwks_url` to the stub (e2e only — no product seam). The journey's relay drops `--no-auth`.

**Tech Stack:** Python 3.14, uv, pytest, `cryptography`, stdlib `http.server`/`socket`, aiohttp test utils (relay tests).

**Spec:** `docs/superpowers/specs/2026-10-03-auth-e2e-design.md`

## Global Constraints

- Always `uv`; Python `>=3.14`. No product-code seam for the key URL: only the e2e `sitecustomize.py` redirects it, only for loopback URLs, only for the stub's tenant.
- Test tenant: `stack.TEST_TENANT` (`11111111-1111-1111-1111-111111111111`); default user `e2e@netbridge.test`; issuer `https://login.microsoftonline.com/{tid}/v2.0`; audience `https://management.azure.com`; JWT header `{"alg": "RS256", "typ": "JWT", "kid": <kid>}`.
- Env names: `NETBRIDGE_E2E_SIGNING_KEY` (PEM path), `NETBRIDGE_E2E_KID`, `NETBRIDGE_E2E_TENANT`, `NETBRIDGE_E2E_UPN` (fake az); `NETBRIDGE_E2E_JWKS_URL` (relay sitecustomize).
- The relay redirect line printed by sitecustomize: `E2E: relay key URL redirected to <url>`.
- Auth matrix: 13 cases × `/ws` and `/tunnel` (spec §5 table), each asserting status and the reason substring from the 401 body; wrong tenant also asserts no JWKS fetch.
- Pentest step: `--strict --skip rapid_connection_dos --skip session_hijack --skip stream_id_enumeration`, 180 s timeout, log to `<work>/logs/pentest.log`, source mode only.
- Unit tests network-free (pytest-socket in shared/relay/agent/socks-proxy); no real waiting.
- The e2e driver stays stdlib + `cryptography` (and runs on Windows).
- Floors only go up; diff coverage ≥ 80% on changed `*/src/` lines (CI gate) — unit-test new driver code.
- Commit messages plain, no Claude attribution / Co-Authored-By lines. Match surrounding style.

## Review Focus

- The fake `az` runs under `NETBRIDGE_E2E_PYTHON` (driver interpreter) on Windows too — signing must work there (Task 2 tests run on the Windows runner via `e2e-windows.yml`).
- Docker image mode: `sitecustomize` must load from a read-only bind mount via `PYTHONPATH` (Task 3 image-mode argv test; real run in Task 5).
- `/status` counts need an authenticated call; `wait_paired` must keep working (Task 3).
- A regression in one validation check must not hide behind another (matrix asserts reasons) — Task 5.
- A dead relay or bad pentest token must not let the pentest step pass — Task 6 precheck/strict tests.

**Files:** Create `e2e/src/netbridge_e2e/relaysite/sitecustomize.py`; Modify `e2e/src/netbridge_e2e/stack.py` (`Relay`); Test `e2e/tests/test_relaysite.py`, `e2e/tests/test_stack.py`.

**Interfaces:** `stack.RELAYSITE_DIR: Path`; `Relay(logs_dir, port, blocked_port, env, image=None, cov=None, auth: AuthStub | None = None)`; with `auth`: argv without `--no-auth`; env adds `NETBRIDGE_ALLOWED_TENANTS=<auth.tenant>`, `NETBRIDGE_E2E_JWKS_URL=<auth.jwks_url>`, and drops `NETBRIDGE_ALLOW_NO_AUTH`; source: `PYTHONPATH=<RELAYSITE_DIR>` (prepended to any existing); image: `-v <RELAYSITE_DIR>:/e2e-site:ro -e PYTHONPATH=/e2e-site`. `Relay.status()` adds `Authorization: Bearer <auth.mint(upn="status@netbridge.test")>` when `auth` is set. `REDIRECTED = r"E2E: relay key URL redirected to "` constant.

`sitecustomize.py`:

```python
"""E2E only: point the relay's key fetch at the local JWKS stub.

Loaded from PYTHONPATH by the e2e driver. Never part of the product: there is
deliberately no configuration seam for the key URL in shared_auth.
"""
import ipaddress
import os
import sys
from urllib.parse import urlsplit

_url = os.environ.get("NETBRIDGE_E2E_JWKS_URL")


def _loopback(host: str | None) -> bool:
    if host == "localhost":
        return True
    try:
        return ipaddress.ip_address(host or "").is_loopback
    except ValueError:
        return False


if _url:
    parts = urlsplit(_url)
    tenant = parts.path.strip("/").split("/")[0]
    if not _loopback(parts.hostname):
        print(f"E2E: refusing to redirect the relay key URL to non-loopback {_url}", file=sys.stderr)
    else:
        from shared_auth import validate

        def _stub_jwks_url(tenant_id: str) -> str:
            if tenant_id != tenant:  # a token for any other tenant must never reach a key
                raise ValueError(f"E2E key stub serves tenant {tenant} only")
            return _url

        validate._get_jwks_url = _stub_jwks_url
        print(f"E2E: relay key URL redirected to {_url}", file=sys.stderr, flush=True)
```
